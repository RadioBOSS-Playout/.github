# RadioBOSS

> One named RadioBOSS hour. Finish the playout. Leave a note the next person can read.

## How RadioBOSS Sits

RadioBOSS does not replace the console, the encoder, or the library you already operate. It sits beside them as a named studio desk for one job: which playout hour is live, which track list still matches live assist, and what the next person should read before the next break.

If two people share a studio PC, each keeps a RadioBOSS style of their own. Extra hours wait for their own title instead of crowding the live playout.

A first visit should be one short live assist hour, then the same RadioBOSS desk the next day. That is enough to see if the clock holds.

## Traffic Light

| Signal | On the RadioBOSS board | What you do |
|--------|----------------------|-------------|
| Green | Named hour, short live track list | Continue the same playout |
| Amber | Two hours mixed in one studio desk | Split the set before you air |
| Red | No title, no note, tracks unlabeled | Stop and name the hour first |
| Clear | Handoff written, live tracks few | Close RadioBOSS and leave the desk |

## Open Order

1. Open the last RadioBOSS playout, not a new empty studio desk.
2. Read the track list and the last handoff.
3. Finish one visible live assist break inside RadioBOSS.
4. Write what changed, then close with fewer unlabeled tracks than you found.
5. If the set feels crowded, drop anything that belongs to a different RadioBOSS hour.
6. Confirm RadioBOSS live assist still points at the station you operate.
7. Leave the studio desk title on the board before you close.

## After a Week

A week in RadioBOSS is not a larger unlabeled folder opened at random. It is the same title, a shorter live track list, and a note that still makes sense before the next hour. Take finished hours off the live set so the next visit starts on the playout that is still open.

Other programs stay where they are. RadioBOSS only keeps the path back: desk name, playout, track list, handoff.

Leave RadioBOSS with a quieter studio desk than the one you opened. The next visit should start on that hour, not in a folder opened at random.

## Sign-off

- [ ] The RadioBOSS workspace name is short enough to scan
- [ ] Only the live hour is on the board
- [ ] A second person can read the handoff
- [ ] The last RadioBOSS playout still opens after a restart
- [ ] Finished hours are off the live RadioBOSS set
- [ ] The RadioBOSS summary still matches the track list
- [ ] Live assist still points at the station you operate

## Field Note

RadioBOSS is easier to trust when the studio desk stays smaller than the music folder it came from. Name the hour, keep the live playout, finish one visible break, and write what changed.

The same loop fits a shop studio, a night log, or a shared studio PC. Open the last RadioBOSS hour and continue. Do not rebuild the clock from scratch.
